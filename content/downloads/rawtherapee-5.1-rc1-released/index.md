We have just released RawTherapee 5.1-rc1. This is a release candidate
for version 5.1. This is not version 5.1 yet. This release is meant for
testing in order to enable us to release a stable 5.1.

Downloads available [from our forum](https://discuss.pixls.us/t/rawtherapee-5-1-rc1-released/4146?u=morgan_hardwood).

If you run into any issues, file a proper bug report as explained
in [RawPedia](http://rawpedia.rawtherapee.com/How_to_write_useful_bug_reports).

Package maintainers can get the code by checking out the
"[5.1-rc1](https://github.com/Beep6581/RawTherapee/releases/tag/5.1-rc1)"
tag in git, or by downloading a no-git-required tarball
from [here](http://rawtherapee.com/shared/source/).

A full list of new features will be made available once 5.1 is released.
If no issues are found with this release candidate, the final release
will be made in about 5 days time.
