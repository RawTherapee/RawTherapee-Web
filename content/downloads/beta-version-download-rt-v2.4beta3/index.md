**Explanation about 'Beta' Releases:**


This release is not a final product, it contains all the features that
will be in final 2.4 but can still contain some bugs.


The idea behind this release is to give users possibility to test and
report bugs back to the RT DevTeam.


**Requirements:**

  - a fast processor with SSE support is recommended (but not required)
  - at least 512 MB of RAM.
  - Minimum recommended screen resolution 1024x768
  - Windows version: Windows 2000, XP or Vista (32bit) is required
  - For the linux version: gtk+ 2.12, gtkmm 2.14 series required

**Download:**

  - Windows version can be downloaded
    [here](http://www.rawtherapee.com/rawtherapee24b3.exe) (SSE
    support).
  - Linux version:
    [rawtherapee24b3.tgz](http://www.rawtherapee.com/rawtherapee24b3.tgz)
    (SSE support), 64-bit version:
    [rawtherapee24b3\_64.tgz](http://www.rawtherapee.com/rawtherapee24b3_64.tgz)
