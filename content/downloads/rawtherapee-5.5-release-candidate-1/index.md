We have just tagged RawTherapee 5.5 Release Candidate 1. You can
download it from the [Downloads](downloads) page. To get the source
code, either clone from git and checkout tag `5.5-rc1`, or get our
[tarball](https://rawtherapee.com/shared/source/) (do not use the
auto-generated GitHub release tarballs). Only important bug fixes and
translation updates are permitted between this release candidate and the
final release. Test it and report issues in
[GitHub](https://github.com/Beep6581/RawTherapee/issues/new) or in the
[forum](https://discuss.pixls.us/c/software/rawtherapee). If all goes
well then we will release RawTherapee 5.5 final in two weeks time.
