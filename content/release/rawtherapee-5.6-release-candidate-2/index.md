We have just tagged RawTherapee 5.6 Release Candidate 2 (this is not the
final 5.6 release yet). Builds for testing available [in the
forum](https://discuss.pixls.us/t/test-rawtherapee-5-6-rc2/12165). To
get the source code, either clone from git and checkout tag `5.6-rc2`,
or get our [tarball](https://rawtherapee.com/shared/source/) (do not use
the auto-generated GitHub release tarballs). Only important bug fixes
and translation updates are permitted between this release candidate and
the final release. Test it and report issues in
[GitHub](https://github.com/Beep6581/RawTherapee/issues/new) or in the
[forum](https://discuss.pixls.us/c/software/rawtherapee). If all goes
well then we will release RawTherapee 5.6 within a week.
