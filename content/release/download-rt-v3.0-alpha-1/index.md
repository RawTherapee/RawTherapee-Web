**Requirements:**

  - a fast processor with SSE support is recommended (but not required)
  - at least 512 MB of RAM.
  - Minimum recommended screen resolution 1024x768
  - Windows version: Windows 2000, XP or Vista (32bit) is required
  - For the linux version: gtk+ 2.12, gtkmm 2.14 series required

**Download:**

  - Windows version can be downloaded
    [here](http://www.rawtherapee.com/rawtherapee30a1.exe) (SSE
    support).
  - Linux version:
    [rawtherapee30a1.tgz](http://www.rawtherapee.com/rawtherapee30a1.tgz)
    (SSE support), 64-bit version:
    [rawtherapee30a1\_64.tgz](http://www.rawtherapee.com/rawtherapee30a1_64.tgz)
  - Source code:
    [rawtherapee30src.tgz](http://www.rawtherapee.com/rawtherapee30src.tgz)

The SVN and issue tracker is maintained by Google code
[here](http://code.google.com/p/rawtherapee/).


Note that the pp2 files created by the older versions are not compatible
with this alpha version. To avoid crashes please delete the old .pp2
files in the directories where you enter with this alpha version. The
options and cache files will not be mixed up since they are stored in a
different directory (named RawTherapeeAlpha).


**Feedback:**

Please note that this is an alpha version. It is neither feature
complete nor bug free. If you have nice ideas, please visit our
[forum](http://rawtherapee.com/forum/) to discuss them with other users
and the author. The bugs are maintained at the google code
[page](http://code.google.com/p/rawtherapee/) of the project.
