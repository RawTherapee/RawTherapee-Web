Many requests have arrived for the old stable builds of RawTherapee,
therefore RT 2.4.1 for Windows (only 32-bit) and for Linux (32-bit and
64-bit) are [available again](/downloads).  

Important notes:  

1.  2.4.1 is a deprecated version, it is not supported anymore.
2.  It was the last stable release before the opening of the source
    code. If you want to download a newer version, take a look at the
    [download center](/downloads). The nightly builds are usually stable
    enough to be used, but not considered as final releases yet.
3.  There was no Macintosh version of the 2.4 branch. If you use mac,
    try a nightly build from the download center.
